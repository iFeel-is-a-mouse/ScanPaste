# ScanPaste — 产品规格说明书

> 最后更新: 2026-05-29 (v4.3 同步)
> 对应代码: ScanPaste v4.3, compileSdk 35, targetSdk 35

## 1. 项目概述

**ScanPaste** 是一个 Android 单页工具 App，核心功能是将摄像头扫描的二维码内容转换为文字并追加到文本编辑区。
支持撤销/重做、文件保存、速记、桌面小部件，内含点击标题触发的 Rabbit Jump 彩蛋游戏。

## 2. 功能范围

### 2.1 文本编辑区

| 特性 | 描述 |
|------|------|
| 位置 | Toolbar 与底部按钮栏之间，NestedScrollView 包裹 |
| 字号 | 固定 18sp |
| 滚动 | 内容超出可视区域时支持上下滚动 |
| 基础编辑 | 支持全选、拷贝、剪切、粘贴等标准剪贴板操作 |
| 光标 | 支持光标定位，追加/撤销/重做后光标自动移至文末 |

### 2.2 按钮组

#### 底部按钮栏（MaterialCardView 包裹）

| 按钮 | 位置 | 描述 |
|------|------|------|
| 撤销 (Undo) | 底部栏左1 | 撤销最近一次编辑（手动输入、扫码追加、清空、速读/导入） |
| 重做 (Redo) | 底部栏左2 | 恢复被撤销的操作 |
| 追加 (Append) | 底部栏左3 | 拍照扫码追加（蓝色醒目 FilledButton） |
| 🖼️相册 | 底部栏右1 | 从相册选图扫码（TextButton 图标） |

#### Toolbar 右侧按钮

| 按钮 | 描述 |
|------|------|
| 清空 | 清空编辑区全部内容（可撤销恢复） |
| 速读 | 从 App 私有存储加载速记；可导入旧 Documents/scanpaste/quicknote.txt |
| 速记 | 保存编辑区内容到 App 私有存储 |
| 保存 | 自定义文件名+扩展名保存到 Documents 目录 |

#### 彩蛋入口

| 入口 | 描述 |
|------|------|
| 点击标题 | 进入 Rabbit Jump 彩蛋游戏（全屏横屏 WebView） |

### 2.3 撤销 (Undo)

- 撤销最近一次编辑：手动输入、扫码追加、清空、速读/导入
- 基于全文快照栈，最大撤销深度 200 次（超出移除最旧快照）
- 新编辑清空 redo 栈；Undo/Redo 双栈
- 追加历史格式：(插入位置偏移量, 追加文本内容)
- 撤销/重做直接恢复全文快照，不再依赖追加位置匹配
- 连续手动输入 500ms 内合并为一个撤销单元
- 快照总字符预算 2,000,000（约 4MB UTF-16），超出淘汰最旧
- EditText 关闭系统原生撤销（`allowUndo=false`），避免双撤销冲突
- 启动时自动加载的速记作为基线，不进入撤销历史
- 撤销/重做后光标移至文末

### 2.4 重做 (Redo)

- 恢复最近一次被撤销的操作
- 双栈分离（Undo Stack + Redo Stack）
- 新的追加/清空操作会清空 Redo Stack
- 可连续重做直到 Redo Stack 为空

### 2.5 追加 (Append)

- 点击后检查 CAMERA 权限 → 启动 ZXing 扫码
- 识别成功自动追加到文本框末尾，光标移至文末
- 每次追加记录到历史栈
- 防抖 500ms

### 2.6 相册扫码

- 点击 🖼️ 图标从系统相册选图
- ZXing 解码图片中的二维码
- 成功追加到文末

### 2.7 保存文件

- 弹出自定义文件名+扩展名对话框
- 默认文件名 "扫码笔记"，默认扩展名 "txt"
- 支持 txt/md/csv/json/xml/html 等格式
- 通过 SAF ACTION_CREATE_DOCUMENT 保存

### 2.8 速记/速读

- 速记：一键保存当前内容到 App 私有存储 `Android/data/com.scanpaste.app/files/Documents/scanpaste/quicknote.txt`（v5.5 起）
- **覆盖提示**：文件已存在时弹窗确认"速记已存在，是否覆盖？"
- **自动备份**：覆盖前将原文件备份到 `quicknote-1.txt` ~ `quicknote-5.txt`；空位优先，5 个满后覆盖修改时间最早的一个
- 速读：一键从 App 私有存储加载内容到编辑区；旧 `Documents/scanpaste/quicknote.txt` 可通过文件选择器导入一次
- 启动时若私有 `quicknote.txt` 存在，自动读入编辑区（不弹选择器）
- 速记保存后触发桌面小部件刷新

### 2.9 桌面小部件

- 展示 quicknote.txt 内容
- 支持可缩放、滚动、圆角、10% 透明背景
- 点击小部件打开 quicknote.txt

### 2.10 彩蛋游戏 (Rabbit Jump)

- 点击 Toolbar 标题进入，全屏横屏 WebView 游戏
- 兔兔从左向右移动，狐狸站在第 15 格
- 第 11-14 格时点击跳跃，精准跳过狐狸即通关
- 通关后速度递增（×1.2）
- 死亡等 3 秒冷却后重来
- 最高纪录持久化到 `Documents/scanpaste/best.txt`
- 游戏角色（🐰🦊）和底部文字从 `Documents/scanpaste/game.txt` 读取，可自定义

## 5. 速记与游戏文件

| 文件 | 用途 | 创建者 |
|------|------|--------|
| `quicknote.txt` | 速记内容 | MainActivity 速记保存时创建 |
| `quicknote-1.txt` ~ `quicknote-5.bak` | 🆕 速记覆盖前的轮转备份 | MainActivity 覆盖时创建 |
| `best.txt` | 彩蛋游戏最高纪录 | RabbitJumpActivity 首次通关时创建 |
| `game.txt` | 彩蛋游戏角色配置（3行） | RabbitJumpActivity 首次启动时创建 |

## 6. 不做什么

- 不保存编辑区历史记录（每次启动为空白）
- 不联网（纯离线 App）
- 不支持除二维码外的其他条码类型
- 不做多文档/多标签
